# TARA Assessment Project Template

This template provides the standard directory structure and toolchain configuration for conducting Threat Analysis and Risk Assessment (TARA) assessments per ISO 21434.

## Project Structure

```
my-tara-project/
├── input/                    # Input documentation and reference materials
│   ├── architecture/         # System architecture diagrams
│   ├── requirements/         # Security requirements
│   └── reference/            # Industry standards, threat libraries
├── data/                     # TARA work products (ISO 21434 outputs)
│   ├── asset_list.md        # Asset identification and analysis
│   ├── ds.md                # Damage scenarios
│   ├── ts.md                # Threat scenarios
│   ├── at.md                # Attack trees (optional but recommended)
│   ├── rt.md                # Risk treatment decisions
│   ├── csg.md               # Cybersecurity goals
│   └── csr.md               # Cybersecurity requirements
├── reports/                  # Generated reports for stakeholder communication
│   ├── overall_report.md     # Executive summary report
│   ├── traceability_report.md # Cross-reference mapping
│   └── multilayer_report.md  # Layered risk architecture view
├── _build/                   # Generated HTML documentation output
│   └── html/                 # Sphinx HTML site generated by tara_export
├── output/                   # Generated stakeholder deliverables
│   └── pdf/                  # Audience-specific PDF reports
├── docs/                     # Sphinx documentation (optional)
│   ├── sphinx/               # Sphinx configuration and build output
│   │   ├── conf.py
│   │   ├── index.rst
│   │   ├── data/             # Sphinx copies of TARA data
│   │   └── reports/          # Sphinx copies of reports
│   └── references.md         # Methodology references
├── references/               # External documents and standards
│   ├── ISO-21434.pdf        # Cybersecurity Management System standard
│   ├── threat-library.md    # Threat enumeration reference
│   └── mitigation-controls.md # Known security controls
├── pyproject.toml           # Python/uv dependencies
├── package.json             # Node.js/bun dependencies (optional)
├── Makefile                 # Build automation
└── README.md                # Project overview
```

## Dependency Management

### Python Dependencies (uv)

**File: `pyproject.toml`**

```toml
[project]
name = "my-tara-assessment"
version = "1.0.0"
description = "Threat Analysis and Risk Assessment per ISO 21434"
readme = "README.md"
requires-python = ">=3.10"
license = {text = "MIT"}
authors = [
    {name = "Your Name", email = "your.email@example.com"}
]

dependencies = [
    # Sphinx documentation
    "sphinx>=7.2.0",
    "sphinx-book-theme>=1.0.0",
    "myst-parser>=1.0.0",
    
    # Markdown processing
    "markdown>=3.5.0",
    
    # Data processing
    "pyyaml>=6.0",
    "toml>=0.10.2",
]

[project.optional-dependencies]
dev = [
    "pytest>=7.4.0",
    "black>=23.0.0",
    "ruff>=0.1.0",
]
pdf = [
    "weasyprint>=60.0",
]

[build-system]
requires = ["setuptools>=68.0", "wheel"]

[tool.black]
line-length = 100
target-version = ["py310"]

[tool.ruff]
line-length = 100
target-version = "py310"
```

**Installation:**
```bash
uv sync
uv pip install -e .
```

**Dependency Notes:**
- **sphinx (7.x)**: Core documentation generation engine
- **sphinx-book-theme**: Professional PyData ecosystem theme for HTML output
- **myst-parser**: Enables Sphinx to process Markdown directly (avoids RST conversion)
- **markdown**: Markdown parsing and validation
- **pyyaml**: Configuration file support
- **weasyprint** (optional): HTML-to-PDF conversion for reports

## Makefile for Automation

**File: `Makefile`**

```makefile
.PHONY: help init sync docs clean validate

help:
	@echo "TARA Assessment Project Commands"
	@echo "=================================="
	@echo "make init          - Initialize project structure"
	@echo "make sync          - Install dependencies (uv)"
	@echo "make docs          - Build Sphinx documentation"
	@echo "make validate      - Validate TARA data files"
	@echo "make clean         - Remove generated files"

init:
	mkdir -p input/{architecture,requirements,reference}
	mkdir -p data
	mkdir -p reports
	mkdir -p _build/html
	mkdir -p output/pdf
	mkdir -p docs/sphinx
	mkdir -p references
	@echo "✓ Project structure initialized"

sync:
	uv sync
	@test -f package.json && bun install || true
	@echo "✓ Dependencies installed"

docs:
	@test -d docs/sphinx || mkdir -p docs/sphinx
	cp data/*.md docs/sphinx/data/ 2>/dev/null || true
	cp reports/*.md docs/sphinx/reports/ 2>/dev/null || true
	sphinx-build -b html docs/sphinx _build/html
	@echo "✓ Documentation built in _build/html"

validate:
	@echo "Validating TARA structure..."
	@test -f data/asset_list.md && echo "✓ asset_list.md" || echo "✗ Missing: asset_list.md"
	@test -f data/ds.md && echo "✓ ds.md" || echo "✗ Missing: ds.md"
	@test -f data/ts.md && echo "✓ ts.md" || echo "✗ Missing: ts.md"
	@test -f data/rt.md && echo "✓ rt.md" || echo "✗ Missing: rt.md"
	@test -f data/csg.md && echo "✓ csg.md" || echo "✗ Missing: csg.md"
	@test -f data/csr.md && echo "✓ csr.md" || echo "✗ Missing: csr.md"

clean:
	rm -rf _build/html
	find . -type d -name __pycache__ -exec rm -rf {} +
	find . -type f -name "*.pyc" -delete
	@echo "✓ Cleanup complete"
```

## Getting Started

### 1. Create Project

```bash
mkdir my-tara-project
cd my-tara-project
git init
```

### 2. Set Up Directory Structure

```bash
mkdir -p input/{architecture,requirements,reference}
mkdir -p data
mkdir -p reports
mkdir -p _build/html
mkdir -p output/pdf
mkdir -p docs/sphinx
mkdir -p references
```

### 3. Copy Configuration Files

Copy `pyproject.toml` and optionally `package.json` to project root.

### 4. Install Dependencies

```bash
# Python toolchain
uv sync

# Node.js toolchain (optional)
bun install
```

### 5. Verify Installation

```bash
# Check Sphinx
sphinx-build --version

# Check Pandoc (for PDF export)
pandoc --version

# Check Python version
python --version
```

### 6. Begin TARA Assessment

Populate `input/` with reference materials, then use OpenCode TaraOK skills to generate TARA work products into `data/`.
